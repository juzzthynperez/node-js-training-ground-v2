# M01 Lab — Dev Environment, Git & GitHub

This folder is the working root for the M01 lab in the shared `node-js-training-ground` repository.

The goal is to take a small Node script through the full branch → pull request → merge cycle, including a deliberately created and resolved merge conflict. The merged history is the evidence.

## Run the script

```bash
node hello-node.js Ana   # Hello, Ana!
node hello-node.js       # Hello, world!
```

Both commands must exit with code 0.
